# 前端手撕题 & 力扣 Hot 100 题解动画

在线打开（GitHub Pages）：

- [力扣 Hot 100 题解动画](pages/%E5%8A%9B%E6%89%A3Hot100.html)：88 道题，每题有逐行步进动画（可以改输入重新跑）、语法着色的代码、核心直觉和重点留意，还有按记忆曲线排的「今日复习」。
- [手写题慢放](pages/%E6%89%8B%E5%86%99%E9%A2%98%E6%85%A2%E6%94%BE.html)：前端手写题的分步动画。
- [手撕练习场](pages/%E6%89%8B%E6%92%95%E7%BB%83%E4%B9%A0%E5%9C%BA.html)：在浏览器里写代码、跑测试。

根目录的 `01-*.js` ～ `11-*.js` 是前端手写题的源码：防抖节流、Promise.all、并发控制、深拷贝、call / apply / bind、EventEmitter、new、数组转树、instanceof、继承、柯里化。

每个页面都是单个 HTML 文件，不需要构建，下载后双击也能打开。复习进度保存在浏览器本地（localStorage），换浏览器或换网址打开时不共享。
