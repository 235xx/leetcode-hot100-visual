# 前端手撕题 & 力扣 Hot 100 题解动画

在线打开（GitHub Pages）：<https://235xx.github.io/leetcode-hot100-visual/>，首页就是「每日学习」主页。本地使用时双击根目录的 `index.html`。

- [每日学习](index.html)：设好每天手撕题几道、力扣题几题，按记忆曲线排出今天的清单（先复习到期的，再学新题，不够再用最久没练的补齐），显示今日进度、连续完成天数、最近 5 周的日历和两边的熟练度。
- [手撕练习场](pages/%E6%89%8B%E6%92%95%E7%BB%83%E4%B9%A0%E5%9C%BA.html)：20 道前端手写题，在浏览器里写代码、跑测试，跑通算完成。
- [力扣 Hot 100 题解动画](pages/%E5%8A%9B%E6%89%A3Hot100.html)：88 道题，每题有逐行步进动画（可以改输入重新跑）、语法着色的代码、核心直觉和重点留意；看完在题目顶部打分（会 / 模糊 / 不会）算完成。
- [手写题慢放](pages/%E6%89%8B%E5%86%99%E9%A2%98%E6%85%A2%E6%94%BE.html)：20 道前端手写题的分步动画。

根目录的 `01-*.js` ～ `20-*.js` 是前端手写题的源码，每个文件底部带测试，`node 文件名` 就能跑：防抖节流、Promise.all、并发控制、深拷贝、call / apply / bind、EventEmitter、new、数组转树、instanceof、继承、柯里化、数组扁平化、map / filter / reduce、大数加法、千分位、URL 参数解析、异步加法、isEqual、洗牌、Ajax 封装。

每个页面都是单个 HTML 文件，不需要构建。每天的题量和复习进度保存在浏览器本地（localStorage），主页和三个页面共用；换浏览器或换网址打开时不共享。
